# 《绿梦：时空之声》Mod 管理器 0.1.9-beta

**新增自由色彩变化功能！可以自由调整莉特莉丝「绮夜寐影」的皮肤色彩了！** 原来的红黑卡位升级为「莉特莉丝 · 绮夜寐影（可调配色）」，保留红黑预设。管理器里点「绮夜寐影配色…」就能打开工作台，六套外观仍可在同一个游戏会话内切换。

**【注意，战斗特效每次更改需要重启游戏，其他配色不用。】**

[下载 Windows 运行包](https://github.com/Arist-1122/lvmeng-mod/releases/download/0.1.9-beta/lvmeng-mod-manager-0.1.9-beta.zip) · [下载源码包](https://github.com/Arist-1122/lvmeng-mod/releases/download/0.1.9-beta/lvmeng-mod-source-0.1.9-beta.zip)

- 眼睛、头发、服装、手套、无人机和战斗闪避残影可分别调色。切到绮夜寐影后，这些颜色可以即时调整，选色会自动保存。
- 「攻击与大招」可选原版蓝白、红黑预设或自选双色。自选配色覆盖已适配的普攻、重击、技能、下落和大招战斗特效，也补了普攻炮线、身后方框、闪光和无人机显隐方块。
- 星潮晶华、里芙 · 爱意凝晶、坎特蕾拉、卡芙卡和伊芙 · 2B 联动服装继续沿用上一版。2B 仍使用先前可运行的材质版本，坎特蕾拉部分姿势可能出现服装穿插。

**想用自选攻击与大招配色，请先设置颜色，再选绮夜寐影启动。** 攻击配色会随当前游戏会话保留。游戏里热切外观后，已经载入的战斗特效会留到退出。要改用另一套攻击色，退出游戏，再用绮夜寐影启动。选择原模型或其他外观开局时，战斗特效使用原版颜色。

下载 Windows 运行包，完整解压到新目录。先退出游戏和旧管理器，再打开 `LvmengModManager.exe`，选择自己已安装的 `Lumin.exe`。选好外观后点「用所选皮肤启动」。手动启动时，等管理器提示助手已就绪，再用自己的启动方式打开游戏。进入莉特莉丝「绮夜寐影」后，可回到管理器应用另一套外观或切回原模型。
