# 0.1.9-Beta-V2

**修复了通过官方启动器启动游戏后，莉特莉丝「绮夜寐影」的战斗特效不替换、仍显示原版蓝白的问题。** 已实机确认。

[下载 Windows 完整运行包](https://github.com/Arist-1122/lvmeng-mod/releases/download/0.1.9-Beta-V2/lvmeng-mod-manager-0.1.9-Beta-V2.zip) · [下载源码包](https://github.com/Arist-1122/lvmeng-mod/releases/download/0.1.9-Beta-V2/lvmeng-mod-source-0.1.9-Beta-V2.zip)

完整解压后打开 `LvmengModManager.exe`。要换攻击与大招配色，请先在工作台设好颜色，再用绮夜寐影启动游戏。**每次更改战斗特效配色需要重启游戏，其他配色可即时调整。** [配色工作台说明与截图](https://github.com/Arist-1122/lvmeng-mod/releases/tag/0.1.9-beta)
