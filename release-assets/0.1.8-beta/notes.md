# 《绿梦：时空之声》Mod 管理器 0.1.8-beta

**红黑特效问题已解决。** 这一版补齐莉特莉丝「绮夜寐影」红黑的战斗特效，仍提供六套外观和同一会话换装。

- 修正红黑的普通命中、第三段 E、空中激光落地及大招战斗特效。上述动作已在独立试用版获得实机确认。
- 修正战斗闪避时头部残影漏蓝。脸部分段和前发的匹配条件已按实机采集的绘制数据修正。
- 星潮晶华与四套跨游戏外观从各自卡片开局时，使用原版战斗特效。六命专属戒指、大招演出和其他角色共用的特效沿用原版。
- 其他五套外观沿用上一公开版。2B 仍使用先前可运行的材质版本，坎特蕾拉部分姿势仍可能出现供体服装的穿插。
- 发行版采用开销更低的图形核心并关闭试用抓帧。游戏仍可能有额外渲染负担，具体取决于硬件和场景，本次整合版的实机帧率待复测。

**要体验完整的新版红黑技能特效，请选红黑开局。** 从其他外观开局再热切到红黑，可以换外观，但本次新增的战斗资源要重开游戏才会启用。从红黑开局后再换到其他外观或切回原模型，游戏已经加载的红色战斗资源会留到退出。需要原版蓝色技能特效时，请退出游戏，再选原模型或其他外观开局。

六套外观为红黑与技能受光、星潮晶华（原创泳装）、里芙 · 爱意凝晶、坎特蕾拉、卡芙卡和伊芙 · 2B 联动服装。展示图与红黑战斗截图可在运行包的 `previews` 目录查看。

下载 Windows 运行包并完整解压到新目录。先正常退出游戏与旧管理器，再打开 `LvmengModManager.exe`，选择自己已安装的 `Lumin.exe`。在列表选好初始外观，点击「用所选皮肤启动」。手动启动时，等窗口提示助手就绪后再从自己的启动方式打开游戏。

进入莉特莉丝「绮夜寐影」后，可在管理器中选另一套并点击「应用所选皮肤」。点「切回原模型」会切回原外观，之后仍可继续换装。试用期间请保留管理器窗口。完整发行包的游戏内换装及客户端更新后的兼容性待复测。
