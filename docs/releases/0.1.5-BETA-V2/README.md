## 0.1.5-BETA-V2（紧急优化帧数）

本机实测，此前启用 Mod 后约 **30 FPS** 的场景，更新后恢复到 **100–110 FPS**。帧率随设备、场景和画质设置变化。

这一版修复了切回原皮后仍会持续的 D3D12 渲染开销。旧版复制每个描述符时会扫描整张堆表，新版只检查实际在用的堆，并保留地址匹配和资源代次校验。同一批 32 个描述符的本机独显隔离测试，复制耗时从约 111–118 微秒降到 1.8–1.9 微秒。

运行包包含莉特莉丝「绮夜寐影」的六套 Mod。外观展示、适配过程和阶段性限制见 [0.1.5-beta 发布说明](https://github.com/Arist-1122/lvmeng-mod/releases/tag/v0.1.5-beta)。

使用新版前先退出游戏和旧管理器。完整解压新版运行包，打开 `LvmengModManager.exe`，选中外观后启动游戏。
