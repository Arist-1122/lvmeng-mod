# v0.1.2 预览版

本版调整管理器和运行器的启动权限处理。普通打开或以管理员身份打开均接受，助手按需要请求权限；自动启动优先使用当前桌面的普通用户上下文。手动模式先等待助手就绪，再由用户从自己的游戏启动器正常进入。

同用户、同会话的普通桌面权限桥接失败或超时会明确停止自动派发，不静默改用管理员启动，也不循环重试，此时可按提示使用手动模式。遇到不同用户或不同会话，应在游戏所在的桌面会话，用该桌面同一用户重新打开整个管理器；手动模式不能代替这一步。若 UAC 已关闭、桌面本身处于高权限或没有桌面 Shell，则按实际环境权限处理，不要求用户调整 UAC。详见[启动权限与排障](启动权限与排障.md)。

本次权限路由修复不代表已完成管理员实机、游戏登录、完整技能画面或性能验收。只读探测和离线验证的结论按实际范围发布，图形与资源覆盖边界继续见[验证与限制](验证与限制.md)。

沿用 v0.1.1 的官网客户端兼容修复：两渠道的已知版本和日常更新统一检查游戏身份、64位架构、Unity 分支、完整渲染来源与最新缓存 Manifest；程序文件改变而渲染条件保持时可继续使用。渲染来源改变或最新清单损坏会明确停止，实际运行时资源守卫保留。

下载 `lvmeng-mod-manager-v0.1.2-preview.zip` 并完整解压，打开管理器选择自己的游戏本体。下载整个源码仓库时，可双击根目录“启动管理器.cmd”离线校验组装。官方登录需要启动器时，选“手动启动游戏”，等待助手就绪后再从自己的官方启动器正常进入。

发布范围继续排除用户设置、本机安装路径、账号/UID、登录鉴权数据与会话诊断。最终 ZIP 的大小、摘要及文件集合见[分发清单](../distribution/manifest.json)、[源码发布清单](../release_manifest.json)和 [SHA256SUMS.txt](../SHA256SUMS.txt)。非商业声明、第三方许可证及游戏资源权利归属沿用仓库说明。
