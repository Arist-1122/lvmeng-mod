# v0.1.0 预览版

完整 ZIP 包含可运行的 Windows Mod 管理器，以及莉特莉丝绮夜寐影的银发、红白黑外观和红黑特效 Mod。选择自己的 Lumin.exe 后，可校验游戏版本、启停和打开运行器；支持继续导入独立适配的其他角色与皮肤 Mod。

本版新增目标表面技能受光与命中/破防星芒补充，并解除安装和运行包固定路径。移除六张完整 stock 纹理，改用稀疏身份指纹及真实上传数据的完整 mip SHA-256。

77 个固定运行文件通过清单与独立包链审查，中文路径迁移、源码重编和篡改拒绝检查通过。新增 Light 2100 次 WARP 对照、命中补充5120次回放与原生管线检查通过。最新完整组合仍待用户实机验收，不把离线验证当作所有动作已经实机通过。
